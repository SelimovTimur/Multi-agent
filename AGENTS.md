# На родном. English — MVP

Правила для тех, кто пишет код в этом репозитории, — человека или агента.
Устройство проекта — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

- `make check` перед коммитом. Красный `make check` — коммита нет.
- Язык комментариев, сообщений об ошибках и документации — русский.
- Документация обновляется в том же коммите, что и код.
- Модуль читает и пишет только свою схему базы; данные чужого домена — через
  Go-интерфейс. Правило проверяет `internal/arch`.
- Применённые миграции не редактируют — только новая пара `.up`/`.down`.
- Общие настройки меняются в `settings.py`, затем `make settings`.
- Ключи API живут только в `.env`, в репозиторий не попадают.
- Названия коммитов — на английском, кратко, с маленькой буквы.

## Интерфейс

- Экраны используют дизайн-систему кабинета: токены и стили из
  `frontend/src/cabinet/cabinet.css`, компоненты из `frontend/src/cabinet/ui.jsx`,
  иконки из `frontend/src/cabinet/icons.jsx`. Отдельного стиля для раздела не
  заводить.
- Акцент английского — красный (`--green*` в `cabinet.css` — исторические
  имена токенов акцента). «Верно», «зачтено» и высокий балл остаются
  зелёными (`--ok*`).
- Заголовки и подписи — обычным регистром, без `text-transform: uppercase` и
  декоративной нумерации. Моноширинные шрифты в интерфейсе не использовать.
