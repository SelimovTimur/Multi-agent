# На родном. English — MVP

Разговорная практика английского с говорящим 3D-аватаром и аналитика для
учителя.

Учитель берёт готовый урок из библиотеки, назначает его классу и выдаёт
задания: на уроке или на дом. Ученик входит по личному коду, читает текст,
повторяет ключевые фразы и голосом разговаривает с аватаром. Аватар ведёт
разговор к целям урока: ученик должен сам употребить нужные фразы и
грамматику. После разговора ученик видит итог, а учитель — аналитику по
классу: кто сколько целей закрыл, какие ошибки повторяются, что повторить на
следующем уроке.

## Запуск

Нужны Docker и два ключа: [OpenRouter](https://openrouter.ai) — движок
разговора, [OpenAI](https://platform.openai.com) — голос аватара (GPT Live),
распознавание и озвучка речи.

```bash
cp .env.sample .env      # впишите OPENROUTER_API_KEY и OPENAI_API_KEY
docker compose up --build
```

Откройте <http://localhost:8088>. При первом запуске команда `seed`
заводит демо-данные и печатает коды учеников:

```bash
docker compose logs seed
```

| Кто | Как войти |
|---|---|
| Учитель | `teacher@example.com` / `english-demo-2026` (меняются в `.env`) |
| Ученик | личный код из лога `seed` или со вкладки «Ученики» класса |

Урок «A school trip to London» уже выдан классу 7А на дом, поэтому ученик
может сразу начать разговор. Микрофон браузер даёт только на `localhost` или
по HTTPS.

## Сценарий проверки

1. Войдите учителем: класс 7А, три ученика, три урока в библиотеке.
2. В другом браузере (или в режиме инкогнито) войдите учеником по коду,
   откройте домашнюю работу и дойдите до разговора с аватаром.
3. Ответьте аватару голосом. Подсказка показывает текст реплики и перевод.
4. Вернитесь к учителю: «Аналитика» класса и страница урока покажут, какие
   цели ученик закрыл и над чем ему поработать.

Другие уроки назначаются из библиотеки кнопкой «Назначить классу», задания
выдаются на вкладке «Уроки» класса.

## Из чего состоит

| Сервис | Что делает |
|---|---|
| `cmd/server`, `internal/` | Go API: вход, классы, уроки, выдача заданий, разговор, аналитика |
| `llm_service/` | Python: движок разговора с аватаром и профили уровней CEFR |
| `asr_service/` | распознавание речи ученика через API |
| `tts_service/` | озвучка реплик аватара в режиме голосовых сообщений |
| `frontend/` | React: кабинет учителя и экраны ученика, 3D-аватар на three.js |
| `migrations/` | схема PostgreSQL |
| `cmd/seed/` | демо-данные; уроки лежат в `cmd/seed/lessons/*.json` |

Подробнее — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Разработка без Docker

```bash
make check        # настройки, gofmt, go vet, границы модулей, тесты Go
make check-all    # плюс сборка и тесты фронтенда и тесты Python-сервисов
```

Интеграционные тесты Go работают с базой, если задан
`NATIVE_TEST_DATABASE_URL`; без него пропускаются. Общие настройки всех
сервисов — в `settings.py`; после правки запустите `make settings`.
